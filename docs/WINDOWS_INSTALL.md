# Windows 安装与卸载

## 当前发布状态

当前仓库只提供经过 GitHub Actions 自动验证的候选安装包，尚未发布正式 GitHub Release。真实 Windows 桌面布局、系统提示和操作体验仍需要人工验收。

候选程序面向 64 位 Windows，安装器不要求管理员权限，默认安装到：

```text
%LOCALAPPDATA%\Programs\DailyBusinessAgent
```

用户数据与程序文件分开保存：

```text
%LOCALAPPDATA%\DailyBusinessAgent
```

## 安装前检查

1. 只从本仓库的正式 Release 获取安装包。
2. 对照 Release 页面公布的 SHA256。
3. 不要安装来源不明、文件名被修改或校验不一致的副本。
4. 当前候选安装包尚未使用商业代码签名证书，Windows SmartScreen 可能显示未知发布者提示。遇到异常发布者名称或不符合文档的权限请求时应取消安装。

PowerShell 校验示例：

```powershell
Get-FileHash .\DailyBusinessAgent-Setup-0.1.0.exe -Algorithm SHA256
```

## 安装步骤

1. 双击安装包。
2. 阅读安装目录和附加选项。
3. “Windows 登录后自动启动”默认只在首次安装时选中，可手动取消。
4. 桌面快捷方式默认不选中。
5. 完成安装后，程序会在本机打开领星页面。

经营报表页面：

```text
http://127.0.0.1:8766/
```

领星页面：

```text
http://127.0.0.1:8766/lingxing
```

服务不应监听公网或局域网网卡。若发现端口 `8766` 绑定到非回环地址，请立即退出程序并按 `SECURITY.md` 报告。

## 数据位置

数据目录可能包含：

- 本地 Agent Token；
- 用户主动上传的任务副本；
- Excel、JSON 和 HTML 结果；
- 领星加密凭据；
- 最近一次成功同步的店铺列表；
- 本地任务状态。

不要公开上传整个数据目录，也不要把它附加到公开 Issue。

## 卸载

可从 Windows“已安装的应用”卸载，或运行安装目录中的卸载程序。

卸载会删除：

- 应用程序文件；
- 开始菜单快捷方式；
- 由安装器创建的登录自启动快捷方式。

卸载不会自动删除 `%LOCALAPPDATA%\DailyBusinessAgent`，避免误删用户原始文件、任务历史、加密配置和生成结果。

需要彻底清理时，应先人工备份需要保留的文件，然后在程序已经退出的前提下手动处理数据目录。

## 自动验证范围

Windows CI 使用静默安装模式验证：

- 安装返回码；
- EXE 存在；
- 登录自启动快捷方式存在；
- `/health`、报表页和领星页可访问；
- 端口只监听回环地址；
- 静默卸载成功；
- 登录自启动快捷方式被移除；
- 预先创建的用户数据文件仍保留。

自动验证不能代替真实电脑上的字体、缩放、SmartScreen、杀毒软件和日常操作体验验收。
