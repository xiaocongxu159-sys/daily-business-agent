# 安全设计

本文描述 Daily Business Agent 公开版本的主要安全边界和失败策略。

## 1. 网络边界

- 默认只监听 `127.0.0.1:8766`；
- 非回环主机配置会在启动前被拒绝；
- 自动化测试检查监听地址不应出现在公网或局域网网卡；
- 本地 HTML 看板不引用 CDN、远程脚本、远程字体或外部图片。

## 2. 本地会话与跨站请求

- Agent Token 在首次运行时随机生成并保存在本地数据目录；
- 正式启动入口不提供打印 Token 的参数；
- 浏览器会话使用安全属性受限的本地 Cookie；
- 修改状态的接口检查本地来源、Referer/Origin 和会话；
- 跨站配置领星、上传文件或触发同步的请求会被拒绝；
- 页面使用 CSP、`X-Frame-Options: DENY` 和 `Cache-Control: no-store` 等响应头。

## 3. 文件与任务隔离

- 每个任务使用独立工作目录；
- 输入和输出路径必须解析在工作目录内部；
- 拒绝路径穿越、Windows 保留名和 Office 临时文件；
- 对单文件和单任务总大小设置上限；
- 公开版只读取用户明确选择的文件，不自动扫描私人目录或历史生产输出；
- 卸载不会递归删除用户数据目录。

## 4. 多店铺身份

数据合并优先使用店铺、站点、日期、身份来源和商品标识组成的复合键。

MSKU 与 Seller SKU 文本相同时，只有旧复合键在数据和映射双方都唯一、且没有更精确主键匹配时才允许兼容回退。出现歧义时保持未匹配，不跨店铺或跨商品合并。

## 5. 输出安全

- Excel 文本以 `=`, `+`, `-`, `@` 开头时会进行公式注入防护；
- HTML 看板只使用刚生成的本地结果；
- 用户文本在进入 HTML 时转义；
- 状态 JSON 不保存 AppSecret、完整代理地址或 Token；
- 公开浏览器测试检查无非本机网络请求。

## 6. 领星凭据

- AppID、AppSecret 和出口地址只从用户本机页面接收；
- 使用 Windows 当前用户 DPAPI 加密后落盘；
- 写入加密包后检查明文 AppSecret 不应出现在文件内容中；
- 页面保存成功后立即清空密码和出口地址输入框；
- 错误信息对凭据字段、Token 和带认证信息的 URL 进行脱敏；
- 断开连接删除加密凭据，但保留最近一次成功店铺数据。

## 7. 固定出口与 TLS

公开仓库只实现客户端连接和证书指纹固定：

- 外层 TLS 证书必须匹配用户配置的 SHA256 指纹；
- 不提供跳过或静默接受不匹配证书的发布配置；
- 不包含固定出口服务器、真实域名/IP、证书、私钥或代理凭据；
- 出口服务器不应存储经营报表。

## 8. 构建供应链

- Windows 构建使用固定版本依赖；
- `pip check` 验证依赖一致性；
- `pip-audit --strict` 在发现已知漏洞时阻止构建；
- PyInstaller 与 Inno Setup 生成候选安装包；
- CI 生成 SHA256 和第三方许可证报告；
- 安装、启动、页面、回环监听、卸载和数据保留均在 Windows Runner 验证。

## 9. 自动测试

测试使用合成店铺、ASIN、SKU、凭据和地址，不使用客户数据。公开 PR 需要通过：

- Python 编译与全量测试；
- 私人标识和私钥标记扫描；
- 真实 Chromium 操作；
- Windows 安装器完整冒烟测试；
- 依赖漏洞审计。

## 10. 非目标

公开仓库不承诺解决：

- 用户电脑已被管理员权限恶意软件控制；
- 用户主动把凭据粘贴到公开渠道；
- 固定出口服务器本身被错误运维；
- 未经验证的第三方重新打包安装程序；
- 未签名候选程序触发的操作系统信誉提示。

发现安全问题请按根目录 `SECURITY.md` 私下报告。
