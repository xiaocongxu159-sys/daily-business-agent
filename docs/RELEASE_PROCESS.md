# 发布流程

Daily Business Agent 使用“源码审查 → 自动候选验证 → 人工桌面验收 → Release”的分阶段流程。

## 1. 版本准备

发布前必须：

- 更新版本号、`CHANGELOG.md` 和安装器元数据；
- 确认公开分支不含私人 Git 历史、生产配置、凭据、证书、客户数据或固定出口服务器部署文件；
- 检查依赖固定版本和第三方许可证；
- 保持领星默认没有任何真实连接参数。

## 2. 自动安全验证

候选提交必须通过：

### Public Security Core

- Python 编译；
- 私人标识、生产路径和私钥标记扫描；
- 本地接口与生命周期测试；
- 路径、上传、公式注入、凭据脱敏和多店铺合并测试；
- 全量合成测试。

### Browser UX

真实 Chromium 必须完成：

- 报表首页加载；
- 合成文件上传和分析；
- Excel 与看板链接；
- 看板商品和销售额数据与渲染；
- 领星页面加载；
- 合成配置、密钥框清空和店铺显示；
- 断开连接和历史数据保留；
- 全程无非本机网络请求。

### Windows Installer

Windows Runner 必须完成：

- 固定依赖安装和 `pip check`；
- 严格漏洞审计；
- 全量测试；
- PyInstaller 和 Inno Setup 构建；
- 安装包大小与 SHA256 检查；
- 静默安装和登录自启动检查；
- 本地健康、报表页、领星页和回环监听检查；
- 静默卸载；
- 快捷方式清理和用户数据保留；
- 候选安装包与第三方许可证报告上传。

任何真实错误或已知漏洞都会阻止后续发布。

## 3. 三轮检查

正式候选至少需要三轮独立检查：

1. 首次完整自动验证；
2. 文档、依赖和许可证清理后的完整验证；
3. 不修改候选源码的独立 CI 重跑。

三轮使用同一候选源码；若第三轮前源码或构建依赖发生变化，应重新开始计数。

## 4. 人工 Windows 验收

自动检查通过后，由人工在真实 Windows 桌面验证：

- 安装向导文字、目录和附加选项；
- SmartScreen 或杀毒软件提示是否符合预期；
- 首次启动、浏览器打开和字体缩放；
- 报表上传、任务进度、Excel 下载和看板体验；
- 领星页面布局、配置提示和断开流程；
- 登录自启动；
- 卸载和用户数据保留。

人工验收不得使用或分享生产密钥、真实证书、私人服务器地址或客户数据截图。

## 5. Release 产物

人工验收通过后，Release 至少包含：

- `DailyBusinessAgent-Setup-<version>.exe`；
- SHA256 校验文件；
- 版本变更说明；
- 第三方依赖许可证报告；
- 已知限制和升级说明。

当前构建没有商业代码签名证书时，Release 必须明确说明安装包未签名，不能声称已签名。

## 6. 发布后验证

Release 发布后再次：

- 从 Release 页面下载文件；
- 重新计算 SHA256 并与公布值比较；
- 在干净 Windows 环境完成安装、启动和卸载；
- 确认默认分支、标签和 Release 指向同一源码版本。

## 7. 回滚与撤回

发现以下情况应立即停止分发并撤回 Release：

- 校验值不一致；
- 安装包包含凭据、客户数据或私人配置；
- 服务监听非回环地址；
- 卸载删除用户数据；
- 依赖审计出现未处理漏洞；
- 安装包与审核源码无法对应。

撤回二进制不会删除用户电脑上的本地数据；需要提供明确的安全升级或卸载说明。
