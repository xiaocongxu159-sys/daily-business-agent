# 领星本地连接说明

领星连接是可选功能。离线报表分析不需要配置领星。

## 普通用户需要准备什么

普通用户只需要准备自己账号对应的：

- 领星开放平台 AppID；
- 领星开放平台 AppSecret。

固定出口服务器、代理用户名、代理密码、TLS 端口和证书 SHA256 指纹都属于企业管理员参数，无法从领星后台、Windows 设置或浏览器中自行找到。

如果页面提示“尚未配置企业管理员固定出口”，请联系负责该工具或网络服务的管理员。不要自行编写服务器地址、账号、密码或证书指纹，也不要把 AppSecret 发到聊天、截图、公开 Issue 或其他不可信渠道。

## 页面布局

“连接领星（普通用户）”区域会直接显示 AppID、AppSecret、同步间隔和自动同步选项。

固定出口信息位于默认收起的“管理员高级设置（普通用户无需填写）”中。只有获得管理员提供的完整安全连接参数后，才应展开并填写。

没有管理员固定出口时，可以继续使用：

- 手工报表上传；
- 本地 Excel 结果；
- 本地经营看板。

## 管理员需要准备什么

管理员需要从自己的受控固定出口环境准备：

- 可用的固定出口 TLS 地址；
- 固定出口代理用户名和密码；
- 外层 TLS 证书的 SHA256 指纹；
- 必要时使用的证书 `server_name`。

公开仓库和安装包不会提供任何真实值，也不包含固定出口服务器部署文件。

## 管理员配置格式

管理员高级设置要求的固定出口地址格式为：

```text
tls+http://用户名:密码@服务器:端口?sha256=64位十六进制证书指纹
```

当连接地址使用 IP、但证书签发给域名时，可增加：

```text
&server_name=证书对应域名
```

这是格式示例，不是可用服务器。不要把真实地址、用户名、密码或指纹写入源码、Issue、截图或聊天记录。

## 保存过程

点击“测试连接并安全保存”后，程序会：

1. 在本机检查必要字段和固定出口格式；
2. 校验外层 TLS 证书 SHA256 指纹；
3. 通过管理员配置的出口测试领星连接；
4. 获取店铺列表；
5. 使用 Windows 当前用户 DPAPI 加密保存连接配置；
6. 清空页面中的 AppSecret 和固定出口地址输入框；
7. 仅在状态中显示脱敏提示和店铺结果。

加密文件只能在相应 Windows 用户上下文中正常解密。复制数据目录到其他用户或电脑并不能保证凭据可用。

## TLS 指纹固定

客户端不会信任配置中任意出现的证书。外层 TLS 连接必须匹配管理员提供的 SHA256 指纹。

指纹要求：

- 64 个十六进制字符；
- 不包含真实私钥；
- 证书轮换时需要由受信任管理员重新核对并更新；
- 不应通过不可信聊天、公开 Issue 或普通截图传递。

## 自动同步

可配置自动同步间隔。程序启动后只在已经保存凭据且自动同步开启时执行检查。

同步失败时：

- 页面继续显示本机最近一次成功数据；
- 错误消息会移除已知凭据；
- 不会把经营报表上传到固定出口服务器；
- 固定出口只用于受控的领星 API 网络访问。

## 断开连接

点击“断开连接”并确认后：

- 删除本地加密连接凭据；
- 停止后续自动同步；
- 保留最近一次成功同步的店铺列表；
- 页面状态显示“已断开”。

需要删除历史店铺数据时，应在程序退出后由用户人工处理本地数据目录。

## 故障排查

- **不知道固定出口是什么**：这是企业管理员服务，不是领星后台字段；普通用户请联系管理员。
- **AppID 或 AppSecret 验证失败**：在领星平台重新确认权限，不要把值发到公开渠道。
- **证书指纹不匹配**：立即停止连接，向出口服务器管理员核实证书，不要关闭指纹校验。
- **固定出口超时**：由管理员检查本机网络和出口服务状态。
- **白名单错误**：确认固定出口公网 IP 已加入用户自己的领星白名单。
- **页面仍显示旧店铺**：这是本地历史数据保留机制，不代表当前连接仍有效。

公开仓库不提供固定出口服务器的部署、运维或生产凭据。
