# 领星本地连接说明

领星连接是可选功能。离线报表分析不需要配置领星。

## 需要准备

使用者需要从自己的受控环境准备：

- 领星开放平台 AppID；
- 领星开放平台 AppSecret；
- 可用的固定出口 TLS 地址；
- 固定出口外层 TLS 证书的 SHA256 指纹。

公开仓库和安装包不会提供任何真实值。

## 配置格式

页面要求的固定出口地址格式为：

```text
tls+http://用户名:密码@服务器:端口?sha256=64位十六进制证书指纹
```

这是格式示例，不是可用服务器。不要把真实地址、用户名、密码或指纹写入源码、Issue、截图或聊天记录。

## 保存过程

点击“测试连接并安全保存”后，程序会：

1. 校验地址格式和证书指纹；
2. 通过用户配置的出口测试领星连接；
3. 获取店铺列表；
4. 使用 Windows 当前用户 DPAPI 加密保存连接配置；
5. 清空页面中的 AppSecret 和出口地址输入框；
6. 仅在状态中显示脱敏提示和店铺结果。

加密文件只能在相应 Windows 用户上下文中正常解密。复制数据目录到其他用户或电脑并不能保证凭据可用。

## TLS 指纹固定

客户端不会信任配置中任意出现的证书。外层 TLS 连接必须匹配用户提供的 SHA256 指纹。

指纹要求：

- 64 个十六进制字符；
- 不包含真实私钥；
- 证书轮换时需要由受信任管理员重新核对并更新；
- 不应通过不可信聊天、公开 Issue 或普通截图传递。

## 自动同步

可配置自动同步间隔。程序启动后只在已经保存凭据且自动同步开启时执行检查。

同步失败时：

- 页面继续显示本机最近一次成功数据；
- 错误消息会移除已知凭据；
- 不会把经营报表上传到固定出口服务器；
- 固定出口只用于受控的领星 API 网络访问。

## 断开连接

点击“断开连接”并确认后：

- 删除本地加密连接凭据；
- 停止后续自动同步；
- 保留最近一次成功同步的店铺列表；
- 页面状态显示“已断开”。

需要删除历史店铺数据时，应在程序退出后由用户人工处理本地数据目录。

## 故障排查

- **AppID 或 AppSecret 验证失败**：在领星平台重新确认权限，不要把值发到公开渠道。
- **证书指纹不匹配**：立即停止连接，向出口服务器管理员核实证书，不要关闭指纹校验。
- **固定出口超时**：检查本机网络和出口服务状态。
- **白名单错误**：确认固定出口公网 IP 已加入用户自己的领星白名单。
- **页面仍显示旧店铺**：这是本地历史数据保留机制，不代表当前连接仍有效。

公开仓库不提供固定出口服务器的部署、运维或生产凭据。
