# Security Policy

## Supported versions

This repository is in pre-release development. No stable version is currently supported.

After the first stable release, supported versions will be listed here.

## Reporting a vulnerability

Please do not disclose security vulnerabilities, credentials, private business data, certificates, tokens, or reproducible exploit details in a public issue.

Use GitHub's private vulnerability reporting feature for this repository when it is available.

When private vulnerability reporting is unavailable, open a public issue containing only a request for private contact. Do not include sensitive details in that issue.

A useful private report should include:

- the affected version or commit;
- the affected component;
- clear reproduction steps using synthetic data;
- the expected and actual behavior;
- the likely security impact;
- any temporary mitigation already tested.

## Sensitive data

Never submit real store data, customer data, API credentials, proxy credentials, TLS private keys, access tokens, passwords, or production configuration to this repository.

Use synthetic examples and reserved test domains or addresses in tests and documentation.
